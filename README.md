# 📦 Sistema de Controle de Estoque

Sistema de controle de estoque desenvolvido em **Python**, com o objetivo de praticar conceitos fundamentais de programação e criar uma aplicação simples para gerenciamento de produtos.

## 🚀 Funcionalidades

- ✅ Cadastro de produtos
- 📋 Listagem de produtos cadastrados
- 🔎 Busca de produtos
- ➕ Adição de estoque
- ➖ Remoção de estoque
- ⚠️ Validação de valores e quantidades
- 🛑 Tratamento de erros com `try/except`
- 🧹 Limpeza e organização das entradas com `.strip()` e `.lower()`

## 🛠️ Tecnologias utilizadas

- **Python 3**
- `os`
- `time`

## 📂 Estrutura do projeto

```text
sistema-controle-estoque/
```

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/hq305/sistema-controle-estoque.git
```

### 2. Acesse a pasta

```bash
cd sistema-controle-estoque
```

### 3. Execute o programa

```bash
python estoque.py
```
